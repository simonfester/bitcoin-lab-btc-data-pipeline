# Generated Dashboards

This folder contains HTML dashboards generated by the Bitcoin Lab data pipeline.

## 📊 Dashboards

### Main Dashboard
**File**: `dashboard.html`
**Generator**: `scripts/dashboard_new.py`

6-pillar on-chain analysis framework:
1. **Valuation** - MVRV, MVRV-Z, AVIV, Price Levels
2. **Profitability** - NUPL, Supply in Profit/Loss
3. **Spending Behavior** - SOPR (all cohorts), Realized P/L
4. **Supply Distribution** - LTH/STH metrics
5. **Activity** - Liveliness, Vaultedness
6. **Miner Health** - Puell Multiple, Difficulty

### Signals Dashboard
**File**: `dashboard_signals.html`
**Generator**: `scripts/dashboard_signals.py`

Actionable trading signals:
- **Entry Signals**
  - Checkmate Signal (4 conditions)
  - Buy The Dip (5 conditions)
  - Additional entry triggers

- **Exit Signals**
  - 8-Metric Exit Detector (cycle extreme detection)
  - STH-MVRV Zones (local top identification)
  - LTH Distribution (HODLer behavior)
  - Additional exit triggers

### Quality Dashboard
**File**: `dashboard_quality.html`
**Generator**: `scripts/dashboard_quality.py`

Data quality monitoring:
- Value range validation
- Cross-metric consistency checks
- Data type validation
- Freshness status

## 🔄 Regenerating Dashboards

### Quick Update
```bash
# From project root
python run.py dashboard-quick
```

### Full Pipeline
```bash
# Sync data + generate dashboards
python run.py dashboard
```

### Individual Dashboards
```bash
# Main dashboard
python scripts/dashboard_new.py

# Signals dashboard
python scripts/dashboard_signals.py

# Quality dashboard
python scripts/dashboard_quality.py
```

## 📂 File Management

**Auto-generated**: All HTML files in this folder are automatically generated.
**Gitignored**: These files are not tracked by git (see `.gitignore`).
**Safe to delete**: You can safely delete these files; they'll be regenerated.

## 🌐 Opening Dashboards

### Command Line
```bash
# macOS
open dashboards/dashboard.html
open dashboards/dashboard_signals.html

# Linux
xdg-open dashboards/dashboard.html

# Windows
start dashboards/dashboard.html
```

### Browser
Double-click any `.html` file to open in your default browser.

## 🔗 Links Between Dashboards

The dashboards include navigation links to each other:
- Main dashboard → Signals dashboard → Quality dashboard
- Easy navigation without leaving the browser

## 📝 Notes

- Dashboards use live price from Coinbase API when generated
- All calculations use pre-computed signals from `data/signals/`
- To update signals, run `python scripts/calculate.py` first
- Dashboards are static HTML (no server required)
